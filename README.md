# Helium S — Android test updates

This public repository distributes **signed test APK binaries and one version manifest only** for the Helium S Android application.

**Source code remains private** at `donnydisart/helium-s-app`. No secrets, signing keys, credentials or customer data should ever be placed in this repository.

## Distribution files

- [Releases](https://github.com/donnydisart/helium-s-updates/releases): versioned `helium-s-signed-debug.apk` files.
- `latest.json`: generated by the trusted private CI after a signed binary has been uploaded. Contains version, Android buildNumber, HTTPS download URL, SHA-256 and short notes.

The Android app may retrieve this manifest and download the corresponding APK over HTTPS. Android's standard installer verifies the app's signing certificate and requires the necessary user approval. There are no guaranteed silent upgrades for normal Android apps.

**Security:** Public APKs can be downloaded by anybody. These are prototypes without real payments or orders. Do not place API tokens, signing secrets or production credentials in the mobile APK. Only accept binaries from the Helium S publishing workflow.
